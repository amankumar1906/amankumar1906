## Building Walkie One

[![Walkie One handhelds in six colours](https://raw.githubusercontent.com/santasailab/walkie-one/main/docs/assets/walkie-one.png)](https://walkieone.com)

Hold the talk button, say what you need, and your message reaches your assistant.
When the reply is ready, press play to hear it.

My work spans the pieces that make that interaction work:

- **Device firmware:** ESP32-S3, cellular connectivity, voice recording, audio playback and power management.
- **Voice and assistant integrations:** speech-to-text, text-to-speech, WebSockets, and Link connections for Claude Code and Codex.
- **Product software:** the macOS companion app, personal server and web experience.
- **Getting it ready to ship:** device provisioning, firmware recovery, automated checks and release tooling.

The public repository includes firmware, a self-hosted server and the standalone
Link connector. Hardware and enclosure files are available from the website.

## What I work with

- **Firmware & hardware:** C++, ESP32-S3, cellular modems, audio and device diagnostics.
- **Servers & integrations:** Python, FastAPI, WebSockets, speech services and AI assistant tooling.
- **Apps & web:** Swift, TypeScript, React and Next.js.

I’m interested in making AI useful outside a chat window, especially voice,
physical interfaces and assistants that can take action with the user’s permission.
